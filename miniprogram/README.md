# 904 班班级账本 · 小程序前端

微信原生小程序，配套后端为本仓库根目录的 express 服务（微信云托管 + MySQL）。
接口契约见仓库根目录 `API.md`。

## 功能

| Tab / 页面 | 说明 |
|---|---|
| 首页 | 蓝渐变余额卡片（收到捐赠 / 累计支出 / 当前余额）+ 最近 10 条动态 + 待审批入口（有权限才显示，带红点）+ 生成分享卡 |
| 明细 | 已公示收支分页列表 → 账目详情（含凭证图预览、登录后可上传凭证） |
| 物资 | 物资出入库台账（登录后可从记账页登记出入库） |
| 记账（需登录） | 捐赠 / 支出（可选"需要审批"）/ 物资入库 / 物资出库四合一表单 |
| 我的 | 微信一键登录（`wx.login` → `/api/auth/wechat`）、邀请码登录、密码登录；审批 / 成员管理入口（按权限显示）；退出登录 |
| 审批页（approve 权限） | 待审批列表，同意 / 驳回（驳回可填原因） |
| 成员页（manage 权限） | 花名册、新增成员、改角色、发放/重发一次性登录邀请码（单个任意成员；批量仅未激活） |
| 分享页 | canvas 绘制蓝渐变分享卡（三个数字 + 最近明细），可分享给好友或保存到相册 |

值日页面 v1 暂不做（后端接口已就绪）。

## 导入微信开发者工具

1. 打开微信开发者工具 → 导入项目
2. **项目目录**选择本仓库的 `miniprogram/` 目录（不是仓库根目录）
3. AppID 已预填 `wx2861b42fc732bdf4`（见 `project.config.json`），用该小程序的管理员/开发者微信扫码登录
4. 编译模式选"普通编译"

> 注意：`miniprogram/` 与后端（`index.js`、`db.js` 等）同属一个 Git 仓库，但小程序项目根是 `miniprogram/`。

## 配置后端域名

生产域名：`https://904api.hoo.ink`（`miniprogram/config.js` 已默认填好）。

如需更换域名：
1. 打开 `miniprogram/config.js`
2. 把 `BASE_URL` 改成新的后端公网域名，末尾不要带斜杠
3. 保存后在开发者工具中点"重新编译"

如果没填就启动，小程序会弹窗提示（`app.js` onLaunch 检查）。

## 预览与真机调试

- 开发者工具内点"预览"生成二维码，用**该小程序 AppID 绑定的体验者微信**扫码即可在手机上打开
- 后端生产域名 `https://904api.hoo.ink` 必须已在小程序后台 → 开发 → 开发设置 → 服务器域名中配置 `request` / `uploadFile` 合法域名，否则真机请求会被拦截；开发阶段可勾选"不校验合法域名"临时绕过
- 分享功能需在真机测试（开发者工具模拟器不支持完整分享流程）

## 登录说明

- **微信一键登录**：调用 `wx.login()` 拿 code，后端用 AppID/AppSecret 换 openid；该微信必须已在花名册中（`members.openid`），否则会提示"未加入花名册，请联系家委会"
- **邀请码登录**：家委会/班主任在"成员管理"页为家长生成 8 位一次性码，在"我的"页输入登录
- **密码登录**：班主任 / 维护者备用通道（后端 `OWNER_PASSWORD`）
- token 存于本地 storage，请求自动带 `Authorization: Bearer`；401/403 会自动跳到"我的"页提示重新登录

```
    ├── members/  成员管理 + 邀请码

```
